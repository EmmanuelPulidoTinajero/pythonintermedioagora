# pythonintermedioagora

## Prácticas

- [Cafetería del campus](cafeteria_campus/README.md): proyecto completo para aprender
  `Depends` en un archivo y organizar productos y pedidos con `APIRouter`.
  Incluye guía para estudiantes, ejercicios y peticiones HTTP.
- [Biblioteca del aula](biblioteca_aula/README.md): API sencilla con FastAPI para
  practicar routing, parámetros y validación de datos. Incluye una versión para
  completar, ejercicios, una guía de repaso y pruebas de avance.
